About this project

What these pages show

Each analysis automatically retrieves all papers matching a set of search terms from OpenAlex, then produces:

  • Publication trends by year, country, and institution
  • Co-authorship and citation networks
  • Study-type classification (RCT, cohort, review, …)
  • Funder landscape and geographic distribution

How it works

The pipeline is fully open source. Set keywords in config.json, then run:

  • python bibliometrics.py — fetch & process
  • python make_dashboard.py — build dashboards
  • ./deploy.sh — push to server

See the GitHub repository for full documentation and source code.
