# UPF Bibliometric Analysis

Goal: retrieve all papers on ultra-processed food from OpenAlex and determine
where the literature comes from — by institution, country, and author.

Use only: requests, pandas, matplotlib, collections. No exotic dependencies.
Target API: OpenAlex (https://api.openalex.org) — free, no key required,
but set a polite mailto param in requests.
Output: CSV files + a printed summary report.
