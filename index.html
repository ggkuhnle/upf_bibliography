Methods & Data

Data source

All publication data is retrieved from OpenAlex — an open, freely accessible scholarly database. No API key is required. Papers are identified by searching titles and abstracts for ultra-processed, ultraprocessed, and NOVA classification.

Coverage

The corpus covers papers published through mid-2025. Institutional affiliation and country are as recorded in OpenAlex; a small fraction of papers (~2 %) lack affiliation data.

Caveats

  • Author-name disambiguation is handled by OpenAlex; occasional mis-attribution may occur.
  • Funding data is incomplete — many papers have no recorded funder.
  • The influence analysis counts citations within the UPF corpus only, not global citations.
  • Books and grey literature are poorly indexed and will be under-represented.

Code

All code is open-source. Scripts: upf_bibliometrics.py (data retrieval), influence_analysis.py (reference network), make_interactive_network.py, make_influence_dashboard.py, make_world_map.py (visualisations). See GitHub for full source.
